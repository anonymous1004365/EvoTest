# Testing Mounted Page Link URLs with Page Parameters

## Instructions

- WHEN the TG encounters a link (e.g., `AbstractLink`, `PageLink`, `BookmarkablePageLink`) that points to a mounted page (using `mountPage` with a path containing parameter placeholders like `{param}`), AND the target page uses `setPageParameters` to populate those parameters
- THEN the TG should test that the URL generated by `link.getURL().toString()` correctly includes the mount path parameter values (e.g., `mount/value/part2`) rather than producing an empty or malformed segment (e.g., `mount//part2`)
  - Use `wicketTester.startPage(...)` to render a page containing the link
  - Retrieve the link via `new PageLink<Void>("linkId", PageWithLink.class)` or similar
  - Call `link.getURL().toString()` to get the URL string
  - Assert that the URL contains the expected mount path (e.g., `assertTrue(url.contains("mount/value/part2"))`)
- Include test cases where page parameters are set via `PageParameters` (e.g., `new PageParameters().set(0, "value")`) and passed to `setPageParameters(parameters)`
- The test should verify the URL format when the link is rendered in context (i.e., after `startPage`)
- Common pitfalls to avoid:
  - Testing the link URL **without rendering the page first** — the mount path resolution may not work correctly unless the page is fully rendered
  - Only testing `link.getPageClass()` or the link destination without checking the final URL string
  - Not testing with actual `PageParameters` that should be substituted into the mount path
  - Assuming that `PageParameters` with `set(0, ...)` or positional parameters are correctly converted to mount path segments without explicit verification

### Correct Example (detects the bug)
```java
// MountedPageLinkTest
wicketTester.startPage(PageWithLink.class);
PageLink<Void> link = (PageLink<Void>) wicketTester.getComponentByPath("link");
String url = link.getURL().toString();
// Expected: mount/value/part2
// Buggy version would produce: mount//part2 (missing the path param)
assertTrue("URL for link should contain 'mount/value/part2', but was: " + url,
    url.contains("mount/value/part2"));
```

### Incorrect Example (would miss the bug)
```java
wicketTester.startPage(PageWithLink.class);
PageLink<Void> link = (PageLink<Void>) wicketTester.getComponentByPath("link");
// Only checking that the link exists, not its URL content
assertNotNull(link);
// Or checking the wrong thing
assertEquals(PageWithLink.class, link.getPageClass());
```
