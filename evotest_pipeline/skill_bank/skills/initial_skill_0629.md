# Random Bit Mask Protocol Validation

## Instructions

- WHEN the TG encounters a test for random bit mask generation in a specific protocol suite (e.g., `TestDummyArithmeticProtocolSuite.testGenerateRandomBitMask`):
  - THEN it should verify that the generated bit mask conforms to the **arithmetic protocol semantics** (e.g., single-bit masks like 0 or 1, not multi-bit booleans like 0xFFFFFFFF).
  - Specifically, for arithmetic protocols, the mask should be a field element representing a single bit (0 or 1 in the underlying field), not a full word mask.
  - The test should generate a mask, check that it is either 0 or 1 (or the field-element equivalent of 0 or 1), and verify consistency across multiple invocations.

- WHEN the test involves a random bit mask that is generated by sampling a random field element and then reducing it modulo 2:
  - THEN the TG should test that the reduction is correct: i.e., the result is either the additive identity (0) or the multiplicative identity (1).
  - Verify that the mask is **not** a random full-width field element, which would be incorrect for arithmetic masking protocols.

- WHEN writing the test, avoid these common pitfalls:
  - ❌ Testing only that the method returns a non-null or non-zero value (too weak).
  - ❌ Assuming that a bit mask for an arithmetic protocol is the same format as a bit mask for a boolean protocol (they differ in representation).
  - ❌ Not checking the range/type of the returned mask value.

## Example (Correct)

```java
// Correct: Verify that the generated random bit mask is a valid arithmetic (single-bit) mask
@Test
public void testGenerateRandomBitMask() {
    // The protocol suite under test is DummyArithmeticProtocolSuite
    // Generate a random bit mask using the arithmetic protocol
    RandomBitMask mask = ... // obtain via the protocol suite
    
    // Assert that the mask represents either 0 or 1 in the underlying field
    // The actual check depends on the field element representation
    int maskValue = mask.asInt(); // or whatever accessor is available
    assertTrue("Bit mask must be 0 or 1 for arithmetic protocol, but was " + maskValue,
               maskValue == 0 || maskValue == 1);
}
```

## Example (Incorrect)

```java
// Incorrect: Only checking non-null is too weak — the buggy version could return
// a random full field element that is not a single-bit mask
@Test
public void testGenerateRandomBitMaskWeak() {
    RandomBitMask mask = ... // obtain via the protocol suite
    assertNotNull("Mask should not be null", mask);
    // This passes even if the mask is an incorrect full-width value!
}
```
